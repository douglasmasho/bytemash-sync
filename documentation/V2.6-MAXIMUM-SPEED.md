## ⚡ **How It Works:**

### **STEP 1: Get Existing (1 query)**
```sql
SELECT p.ID, pm.meta_value as sku 
FROM wp_posts p 
INNER JOIN wp_postmeta pm ON p.ID = pm.post_id 
WHERE pm.meta_key = '_sku' 
AND pm.meta_value IN ('SKU1', 'SKU2', ... 'SKU50')
```

### **STEP 2: Bulk Update with CASE (1 query)**
```sql
UPDATE wp_posts SET 
  post_title = CASE 
    WHEN ID=101 THEN 'Product 1'
    WHEN ID=102 THEN 'Product 2'
  END,
  post_content = CASE 
    WHEN ID=101 THEN 'Description 1'
    WHEN ID=102 THEN 'Description 2'
  END
WHERE ID IN (101,102,...)
```

### **STEP 3: Bulk Insert New (1 query)**
```sql
INSERT INTO wp_posts (...) VALUES
(1, 'Product 1', 'product-1', 'Desc 1', ...),
(1, 'Product 2', 'product-2', 'Desc 2', ...),
... 40 products ...
```

### **STEP 4: Get New IDs (1 query)**
```sql
SELECT ID, post_name 
FROM wp_posts 
WHERE post_name IN ('product-1', 'product-2', ... 'product-40')
AND post_type = 'product'
```

### **STEP 5: MEGA Meta Insert (1 query)**
```sql
INSERT INTO wp_postmeta (post_id, meta_key, meta_value) VALUES
(201, '_sku', 'SKU1'),
(201, '_price', '0'),
(201, '_regular_price', '0'),
(201, '_manage_stock', 'yes'),
(201, '_stock_status', 'instock'),
... ~13 meta per product ...
(202, '_sku', 'SKU2'),
... ~520 total entries for 40 products in ONE query ...
```

### **STEP 6: MEGA Lookup Insert (1 query)**
```sql
INSERT INTO wp_wc_product_meta_lookup (...) VALUES
(201, 'SKU1', 0, 0, 0, 0, 0, 0, 'instock', 0, 0, 0, 'taxable', ''),
(202, 'SKU2', 0, 0, 0, 0, 0, 0, 'instock', 0, 0, 0, 'taxable', ''),
... 40 entries in ONE query ...
ON DUPLICATE KEY UPDATE sku = VALUES(sku)
```

### **STEP 7: Assign Categories (~50 queries)**
```php
// Can't easily bulk this with pure SQL
foreach ($products as $product) {
    wp_set_object_terms($product_id, $category_ids, 'product_cat');
}
```

**Total: ~58 queries for 50 products** (vs ~2,150 before!)
